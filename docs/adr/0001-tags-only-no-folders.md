# 只有标签，没有文件夹

书签唯一的组织手段是标签（多对多），不存在文件夹/层级概念；导入浏览器 Netscape HTML 时，文件夹路径的每一段（如"书签栏/开发/前端"）各自映射为一个标签。选择标签是因为其多对多的表达力天然覆盖文件夹的用途，文件夹层级对个人工具是过度设计；拆段映射而非整条路径拼成单标签，是为了让导入的浏览器分类与手工标签自然汇流，不制造只含一两个成员的"伪文件夹"。

## Consequences

- 导入浏览器书签后标签数量会明显增多（每层文件夹名都成为一个标签），这是有意为之。
- 导出 Netscape HTML / Markdown 时按标签重建分组：每个标签一个组，多标签书签出现在多个组里。
- 将来若要引入文件夹，需要数据迁移，成本高。
